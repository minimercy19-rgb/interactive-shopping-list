# Interactive Shopping List

A simple web application that lets users create and manage a shopping list.  
Users can add items with prices, mark them as purchased, edit or delete items, and see the total cost.

## Features

- Add items with name and price
- Mark items as purchased  
- Edit existing items
- Delete individual items
- Clear the entire list
- Calculation of:
  - Total of purchased items
  - Total of all items
- Clean and responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript 

 
## Assignment Requirements Covered

- Maintain shopping list items in a JavaScript array
- Dynamically add items to the DOM
- Mark items as purchased
- Clear the list
- Edit existing items
- Display total cost of purchased items
